Extensão Chrome

Política de Privacidade

IA Assist Exportador de Serviços  ·  Última atualização: outubro de 2026

1Sobre esta extensão

O IA Assist Exportador de Serviços é uma extensão Chrome desenvolvida para uso interno corporativo. Seu único propósito é ler dados de Ordens de Serviço exibidos nos portais das seguradoras/assistências atendidos (Juvo/Tempo, Notro, Aciona Fácil, Tokio, Mondial, Maxpar, Veniti, MIA/MAWDY, Porto Seguro, NEO) e em mensagens do WhatsApp Web selecionadas pelo usuário, e exportá-los para o sistema IA Assist, usando a sessão que o próprio usuário já tem aberta no IA Assist.

Esta extensão não vende, compartilha nem monetiza dados de nenhum usuário. A leitura das ordens de serviço ocorre localmente no navegador do usuário. A única informação enviada ao desenvolvedor são registros de erro sem dados pessoais, que o usuário pode desligar (ver seção 3).

Tudo começa desligado (a partir da versão 2.0.20): ao instalar ou atualizar, nenhuma função automática (exportar sozinho, dar baixa, avisar serviço novo, aceitar/recusar pelo aviso, aviso de chegada) vem ligada. Um aviso no IA Assist apresenta as novidades e o usuário escolhe o que ativar, portal por portal.

2Dados acessados pela extensão

Quando o usuário aciona manualmente o mapeamento, a extensão lê os seguintes dados exibidos na página da plataforma Juvo:

Dado Finalidade Armazenado?
Nome do assegurado Compor o payload de exportação Não
Endereço do assegurado Compor o payload de exportação Não. Exceção: vai no registro de erro, quando houver (seção 3)
Telefone do assegurado Compor o payload de exportação Não
Dados da OS (serviço, datas, etc.) Compor o payload de exportação Não. Exceção: vão no registro de erro, quando houver (seção 3)
URL da API (configurada pelo usuário) Destino do envio Sim — chrome.storage.sync
Token de API (configurado pelo usuário) Autenticação na API Sim — chrome.storage.sync

Os dados da OS são enviados exclusivamente para a URL de API configurada pelo próprio usuário e descartados imediatamente após o envio. Os dados pessoais do segurado (nome, telefone, CPF, placa e chassi) nunca são gravados em disco, banco de dados local ou serviço de terceiros. A única exceção a este parágrafo é o registro de erros descrito na seção 3, que é enviado sem esses dados.

Origem da exportação (a partir da versão 2.0.20): na observação da ordem de serviço enviada ao IA Assist, a extensão acrescenta de onde ela veio — "via exportador automático" ou "exportado pelo operador" — para distinguir no IA Assist. É só um texto; nenhum dado pessoal a mais.

Consulta de CEP (a partir da versão 2.0.12): quando o portal da seguradora não informa a rua do atendimento, mas informa o CEP, a extensão consulta esse CEP no ViaCEP (viacep.com.br), um serviço público de endereços, para completar a rua. Somente o CEP é enviado nessa consulta, sem nenhum dado do segurado. O endereço só é usado se a cidade do CEP for a mesma da ordem de serviço.

Portais abertos em segundo plano e aviso de serviço novo (a partir da versão 2.0.14): para o usuário não precisar deixar cada portal de seguradora aberto, a extensão abre as telas de acompanhamento desses portais numa janela minimizada do próprio navegador, usando a sessão (login) que o usuário já fez no navegador. Só são abertos os portais que o usuário já utilizou com login. Nessas telas a extensão lê os números das ordens de serviço e os avisos de serviço novo para aceitar, do mesmo jeito que faz nas abas abertas pelo usuário, e mostra o aviso na tela do IA Assist. A extensão não lê a senha salva no navegador; quando a sessão expira, ela pede que o próprio usuário entre de novo — ou, se o usuário escolheu guardar o login daquele portal, entra com ele (ver "Login guardado nos portais", abaixo). O recurso pode ser desligado no popup, em "Exportação automática".

Leitura dos portais sem abrir abas (a partir da versão 2.0.20): nos portais em que a tela vem pronta do servidor (Aciona Fácil e Mondial), a extensão pede a mesma página que a aba abriria, usando a sessão (login) que o usuário já fez no navegador, e lê os números das ordens de serviço e os avisos de serviço novo sem abrir janela nem aba. Os dados lidos têm o mesmo uso descrito nesta seção. Quando a sessão expira, aparece só um aviso no IA Assist para o usuário entrar de novo. O recurso respeita o que o usuário desligou no popup.

Empresa logada no portal (a partir da versão 2.0.20): para quem tem mais de uma empresa no IA Assist, a extensão lê na tela do portal o nome da empresa logada e, se for diferente da empresa do IA Assist, pergunta ao usuário antes de exportar sozinha as ordens de serviço daquele portal. O nome da empresa e a resposta ficam só no computador do usuário e não são enviados a lugar nenhum.

Trabalho sem abrir abas (quadro dentro da página) (a partir da versão 2.0.20): para não ficar abrindo abas no computador do usuário, a exportação, a baixa, a leitura da oferta e o login automático passam a rodar num quadro invisível dentro de uma aba do portal que já está aberta (a do próprio usuário, quando ele está sem mexer nela há 30 segundos, ou uma aba na janela minimizada da extensão). Nada aparece na frente do usuário e nenhuma aba nova é aberta para isso. Se não houver uma aba do portal, o trabalho espera. A opção "Manter aberto em segundo plano" (uma janela minimizada) é escolhida pelo usuário, portal por portal, e vem desligada. Nos portais em que o login vale só na aba em que foi feito (MAWDY, Veniti, NEO, Maxpar), quando o usuário liga essa opção a extensão leva a aba já logada dele para a janela minimizada, sem recriar o login.

Leitura da Tempo e da Notro sem aba (a partir da versão 2.0.20): para saber se há serviço novo sem manter o portal aberto, a extensão usa o login que a própria página desses portais guarda (o token de sessão da Tempo e da Notro). Esse token é lido quando o usuário está com o portal aberto e fica só na memória do navegador (é apagado quando o Chrome fecha); nunca é gravado em disco nem enviado ao desenvolvedor, ao IA Assist ou a terceiros. É usado apenas para consultar, no servidor do próprio portal, a contagem de serviços e a lista de solicitações — nunca para aceitar, recusar ou alterar nada.

Login guardado nos portais (opcional)

A partir da versão 2.0.20, o usuário pode escolher, portal por portal, guardar o usuário e a senha que usa no portal da seguradora, para a extensão entrar sozinha quando a sessão expirar. É opcional: sem essa escolha, nenhuma senha é guardada.

Dado Finalidade Onde fica
Usuário e senha do portal (informados pelo próprio usuário) Entrar naquele mesmo portal quando a sessão expira Só no computador do usuário (chrome.storage local), criptografados
PIN criado pelo usuário Proteger os logins guardados Não é guardado (só uma chave tirada dele)
  • Usuário e senha são criptografados com AES-GCM de 256 bits, com uma chave tirada do PIN do usuário (PBKDF2-SHA256, 310 mil iterações). O PIN não é guardado.
  • Por padrão, depois de digitado o PIN, a chave fica só na memória do navegador. Se o usuário marcar "Não pedir o PIN de novo neste computador", a chave fica guardada nesse computador como chave não exportável do navegador; nesse caso, quem usar o mesmo usuário do computador consegue fazer a extensão entrar nos portais, como acontece com as senhas salvas no próprio navegador.
  • Os logins nunca saem do computador: não são enviados ao desenvolvedor, ao IA Assist, ao registro de erros nem a terceiros. São usados apenas para entrar no próprio portal ao qual pertencem.
  • Ficam separados por empresa do IA Assist e por portal. O usuário pode apagar o login de um portal, ou todos, a qualquer momento no popup; desinstalar a extensão também os apaga.
  • Para não bloquear a conta do usuário no portal, depois de uma senha recusada a extensão não tenta de novo sozinha, e faz no máximo 3 tentativas por hora. Ela nunca derruba outra sessão aberta com o mesmo usuário.

Confirmação de chegada (a partir da versão 2.0.15): quando uma ordem de serviço do Aciona Fácil, da Tempo/Juvo ou da Mondial passa para "em execução" no IA Assist (técnico no local), a extensão confirma a chegada no portal da seguradora digitando o código que o próprio portal pede — os 4 últimos dígitos do telefone do cliente, lido na tela da ordem de serviço. Esse código é usado só dentro do portal, não é gravado nem enviado a outro lugar. Cada portal pode ser desligado no popup, em "Exportação automática".

Conferir e corrigir o cadastro no IA Assist (a partir da versão 2.0.16): quando a exportação é recusada por cadastro, ou quando o usuário pede no popup, a extensão lê no IA Assist, com a sessão do próprio usuário, a lista de pessoas, o cadastro da seguradora e o cadastro de cidades, aponta o que falta (seguradora, produto, serviço, cidade ou região) e abre a tela da correção já preenchida. Nada é salvo sem o usuário clicar em "OK, salvar". CPF/CNPJ, telefones e e-mails do cadastro não saem da página.

Uma janela só e atualização automática (a partir da versão 2.0.19): o trabalho em segundo plano (portais abertos, exportação automática, confirmação de chegada) fica em abas de uma única janela minimizada da extensão. A extensão também confere na Chrome Web Store se há versão nova e, quando o Chrome já a baixou, reinicia a si mesma num momento sem trabalho em andamento, para o Chrome instalar a atualização. Nenhum dado do usuário ou do segurado é enviado por isso.

WebPrestador — aprendizado, opcional (a partir da versão 2.0.19): o portal WebPrestador (app.webprestador.com.br) ainda não é lido pela extensão. Para prepará-lo, o usuário que trabalha com ele pode ligar, no popup ("Exportação automática" → "Aprender a WebPrestador"), uma permissão opcional de acesso a esse site — o Chrome pede a autorização só a quem ligar, e ela pode ser desligada no mesmo lugar. Com ela ligada, a extensão não lê nem exporta ordens de serviço desse portal: apenas envia ao suporte cópias das telas (no máximo uma por tela por hora e 12 por dia, sem a tela de login e com a mesma remoção de dados pessoais da seção 3) e a sequência de passos quando o usuário aceita ou recusa um serviço, para aprender como os serviços chegam e como são exibidos.

Mensagens do WhatsApp Web

A partir da versão 2.0, a extensão também consegue montar uma ordem de serviço a partir de uma mensagem recebida no WhatsApp Web, quando a seguradora envia o acionamento por lá em vez de um portal.

Isso acontece somente por ação explícita do usuário: ele seleciona o texto da mensagem com o mouse e clica no ícone da extensão. Sem essa seleção e esse clique, a extensão não tem acesso nenhum à página do WhatsApp.

Dado Finalidade Armazenado?
Texto que o usuário selecionou na mensagem Extrair os campos da OS (protocolo, endereço, serviço, agendamento) Não
Nome da conversa aberta Lembrar qual corporativo e produto o usuário escolheu naquela conversa Sim — chrome.storage local, no computador do usuário

O conteúdo da mensagem não é transmitido nem gravado. A leitura do texto e a montagem da ordem de serviço acontecem inteiramente dentro do navegador do usuário. O que sai do computador são apenas os campos da OS já montados, para a mesma API do IA Assist usada pelos portais — exatamente como acontece com qualquer outra exportação.

A extensão não declara permissão de acesso ao domínio do WhatsApp. O acesso é concedido pelo próprio navegador, para aquela aba, no momento em que o usuário clica no ícone, e expira quando ele sai da aba.

A extensão não lê a lista de conversas, não lê outras conversas, não lê mensagens não lidas e não lê nada que o usuário não tenha selecionado. Também não envia mensagens pelo WhatsApp em nenhuma hipótese.

Melhoria da leitura (a partir da versão 2.0.19): quando a leitura de uma mensagem selecionada dá problema (protocolo não encontrado, campo não lido, envio recusado ou linha não reconhecida), a extensão envia ao suporte apenas a estrutura da mensagem — os nomes dos rótulos da ficha (por exemplo "PROTOCOLO", "SERVIÇO", "TEL"), a forma das linhas que não reconheceu (as letras trocadas por "A" e os números por "9"), os nomes dos campos lidos e dos que faltaram, o serviço, o corporativo, o produto e a UF. O texto da mensagem, nomes, telefones, endereços e o número do protocolo não são enviados, e não há cópia da tela do WhatsApp. No máximo 15 envios por dia; desliga junto com o registro de erros (seção 3).

3Registro de erros para o suporte

A partir da versão 2.0.10, quando a extensão não consegue ler ou exportar uma ordem de serviço, ela envia um registro do erro ao suporte do IA Assist. Assim o problema é identificado e corrigido sem que o usuário precise enviar arquivos ou capturas de tela.

Dado enviado Finalidade
Tipo do erro e mensagem técnica Saber o que falhou (campo não lido, OS recusada etc.)
Versão da extensão, portal e número da OS Localizar o caso e a versão afetada
Nome da empresa no IA Assist Saber qual cliente foi afetado
Identificador aleatório da instalação Agrupar erros repetidos. Não identifica a pessoa.
Cópia do texto da tela onde o erro ocorreu, sem dados pessoais Reproduzir e corrigir a leitura do portal
Antes do envio, a extensão remove nome, telefone, CPF/CNPJ, e-mail, placa e chassi do segurado, tanto dos campos da ordem de serviço quanto do texto da tela. São mantidos o bairro, a cidade, o serviço e o modelo do veículo, que são os dados necessários para corrigir a leitura. A partir da versão 2.0.17, a rua, o número, o complemento, o ponto de referência e o CEP também são removidos, assim como nomes de técnicos e do usuário logado no portal.

Os registros ficam armazenados no Supabase, em servidores localizados em São Paulo (Brasil). São acessados apenas pela equipe de suporte, não são compartilhados nem vendidos e são apagados automaticamente após 60 dias. O envio ocorre quando há um erro e, a partir da versão 2.0.15, também para registrar o resultado (sucesso ou erro) de cada confirmação de chegada automática, com o número da OS, o portal e a empresa — sem o telefone nem o código digitado. A partir da versão 2.0.16, também registra os passos da inclusão de serviço no cadastro (nomes da seguradora, do corporativo, do serviço e da empresa) e, a cada 5 minutos, consulta a configuração definida pela equipe de suporte (liga/desliga de recursos e avisos), informando apenas o nome da empresa. Quando um serviço novo toca num portal, também é enviada uma cópia da tela da oferta (botões e texto, com nome, telefone, CPF e e-mail ocultos) e, nos portais MAWDY, Veniti, NEO, Maxpar e Porto Seguro, uma cópia diária da tela da listagem de serviços, no máximo 4 por portal por dia, para preparar o aceite do serviço direto pelo aviso. A partir da versão 2.0.17, quando o operador aceita ou recusa um serviço num portal, também é enviada a sequência de passos que ele fez (nomes dos botões, das janelas e das opções escolhidas), sem o que foi digitado e sem nomes de pessoas, no máximo 8 por portal por dia, para ensinar a extensão a aceitar e recusar pelo aviso. A partir da versão 2.0.18, também registra: quando a UF de uma OS é corrigida pela lista de municípios do IBGE (cidade, UF lida e UF final) ou não pode ser definida (a OS fica para conferência); e, quando a sessão de um portal cai, os horários e os minutos desde o login e sem atividade, para ajustar a manutenção da sessão — sem dado pessoal. A lista de municípios do IBGE vai dentro da extensão: nada é enviado para consultá-la. A partir da versão 2.0.19, também registra: a versão de/para quando a extensão se atualiza sozinha; a estrutura das mensagens do WhatsApp cuja leitura deu problema (seção 2, sem o texto); o endereço (sem números) das telas de portal em que a leitura automática não é feita; e, só para quem ligou o aprendizado da WebPrestador, as cópias de tela e os passos descritos na seção 2. A partir da versão 2.0.20, para preparar o trabalho com os portais sem abrir abas em segundo plano, também registra a forma das chamadas que as páginas dos portais fazem aos próprios servidores: o método, o endereço com os números e códigos trocados por um marcador, o código de resposta, os nomes dos campos enviados e recebidos (sem os valores), se a chamada leva identificação de login (sim/não, sem o código) e, quando houver, o nome do botão de ação clicado logo antes (ex.: "aceitar", "confirmar"). Cada chamada distinta no máximo uma vez por dia, até 50 por portal por dia. Nunca são enviados senhas, códigos de login, cookies, dados de clientes ou o conteúdo das respostas. Nos portais que usam mensagens contínuas (Tempo) ou consultas GraphQL (Notro), o mesmo vale para a forma dessas mensagens: o tipo da mensagem, o canal (sem números), os nomes dos campos e o texto da consulta escrita no próprio portal, com qualquer valor trocado por um marcador. Também a partir da versão 2.0.20, registra: o resultado do login automático, para quem guardou o login (por exemplo "conectado" ou "senha recusada" — nunca o usuário ou a senha); e se a leitura sem abas funcionou em cada portal. Também registra o estado de conexão de cada portal (conectado ou desconectado), para o suporte saber se o cliente conseguiu entrar — sem usuário, senha ou qualquer dado pessoal. Fora disso, a extensão não envia nada durante o uso normal.

Volumetria (a partir da versão 2.0.20): para o relatório mensal de quantas ordens de serviço passam por cada empresa do IA Assist e por cada portal, a extensão envia, para cada OS, uma única vez: o portal, o tipo do evento (lida na listagem, oferecida para aceitar, aceita ou recusada pelo aviso) e um código embaralhado (hash) da OS — o número da OS não é enviado. Vão junto o nome da empresa no IA Assist e o identificador aleatório da instalação. Nenhum dado de cliente ou segurado. Esses números ficam no mesmo Supabase por até 13 meses e desligam junto com o envio de erros (abaixo).

O usuário pode desligar este envio a qualquer momento no popup da extensão, em "Diagnóstico e suporte" → "Enviar erros automaticamente ao suporte".

4O que a extensão NÃO faz

  • Não rastreia histórico de navegação
  • Não monitora atividade do usuário (cliques, teclado, mouse), exceto a sequência de passos de aceite e recusa de serviço nos portais e o nome do botão de ação ligado a uma chamada do portal, descritos na seção 3 (sem o que foi digitado)
  • Não acessa páginas fora dos portais de seguradora listados e do IA Assist (o WhatsApp Web só com a seleção e o clique do usuário; a WebPrestador só se o usuário ligar a permissão opcional)
  • Não lê as senhas salvas no navegador e não guarda senhas dos portais das seguradoras — a não ser que o próprio usuário escolha guardar o login de um portal (seção 2); nesse caso ficam só no computador dele, criptografadas, e nunca são enviadas a lugar nenhum
  • Não executa código carregado de servidores externos
  • Não usa eval() nem carrega scripts remotos
  • Não envia dados pessoais para servidores do desenvolvedor da extensão. Envia apenas registros de erro sem dados pessoais, que podem ser desligados (seção 3).
  • Não vende, compartilha nem transfere dados a terceiros
  • Não usa dados para publicidade, perfis ou scoring

5Armazenamento local

A extensão utiliza chrome.storage.sync exclusivamente para salvar:

  • A URL da API do IA Assist (inserida pelo usuário)
  • O token de autenticação da API (inserido pelo usuário)

Esses dados são armazenados de forma sincronizada com a conta Google do usuário pelo próprio mecanismo do Chrome. O usuário pode removê-los a qualquer momento desinstalando a extensão ou limpando os dados de extensões nas configurações do Chrome.

No próprio computador (chrome.storage local e IndexedDB da extensão), a extensão também guarda as preferências do popup e, só para quem escolheu, os logins dos portais criptografados e a chave de "não pedir o PIN de novo" (seção 2). Nada disso é enviado.

Nenhum dado pessoal de segurados é armazenado em nenhum momento.

6Segurança

  • Toda comunicação com a API ocorre exclusivamente via HTTPS
  • A extensão bloqueia ativamente envios para URLs sem HTTPS
  • O token de API é transmitido apenas no cabeçalho Authorization da requisição
  • Logins de portal guardados pelo usuário (opcional): criptografia AES-GCM de 256 bits com chave tirada de um PIN do usuário (PBKDF2-SHA256), apenas no computador dele
  • Todo o código da extensão é incluído no pacote — nenhum código remoto é carregado nem executado

8Contato

Em caso de dúvidas sobre esta Política de Privacidade, entre em contato com o desenvolvedor responsável pela extensão através do painel da Chrome Web Store ou diretamente com o administrador do sistema IA Assist da sua organização.
