IA Assist Exportador de Serviços  ·  Última atualização: setembro de 2026

1Sobre esta extensão

O IA Assist Exportador de Serviços é uma extensão Chrome desenvolvida para uso interno corporativo. Seu único propósito é ler dados de Ordens de Serviço exibidos na tela da plataforma Juvo e exportá-los para o sistema IA Assist por meio de uma API configurada pelo próprio usuário.

Esta extensão não vende, compartilha nem monetiza dados de nenhum usuário. A leitura das ordens de serviço ocorre localmente no navegador do usuário. A única informação enviada ao desenvolvedor são registros de erro sem dados pessoais, que o usuário pode desligar (ver seção 3).

2Dados acessados pela extensão

Quando o usuário aciona manualmente o mapeamento, a extensão lê os seguintes dados exibidos na página da plataforma Juvo:

Dado Finalidade Armazenado?
Nome do assegurado Compor o payload de exportação Não
Endereço do assegurado Compor o payload de exportação Não. Exceção: vai no registro de erro, quando houver (seção 3)
Telefone do assegurado Compor o payload de exportação Não
Dados da OS (serviço, datas, etc.) Compor o payload de exportação Não. Exceção: vão no registro de erro, quando houver (seção 3)
URL da API (configurada pelo usuário) Destino do envio Sim — chrome.storage.sync
Token de API (configurado pelo usuário) Autenticação na API Sim — chrome.storage.sync

Os dados da OS são enviados exclusivamente para a URL de API configurada pelo próprio usuário e descartados imediatamente após o envio. Os dados pessoais do segurado (nome, telefone, CPF, placa e chassi) nunca são gravados em disco, banco de dados local ou serviço de terceiros. A única exceção a este parágrafo é o registro de erros descrito na seção 3, que é enviado sem esses dados.

Consulta de CEP (a partir da versão 2.0.12): quando o portal da seguradora não informa a rua do atendimento, mas informa o CEP, a extensão consulta esse CEP no ViaCEP (viacep.com.br), um serviço público de endereços, para completar a rua. Somente o CEP é enviado nessa consulta, sem nenhum dado do segurado. O endereço só é usado se a cidade do CEP for a mesma da ordem de serviço.

Portais abertos em segundo plano e aviso de serviço novo (a partir da versão 2.0.14): para o usuário não precisar deixar cada portal de seguradora aberto, a extensão abre as telas de acompanhamento desses portais numa janela minimizada do próprio navegador, usando a sessão (login) que o usuário já fez no navegador. Só são abertos os portais que o usuário já utilizou com login. Nessas telas a extensão lê os números das ordens de serviço e os avisos de serviço novo para aceitar, do mesmo jeito que faz nas abas abertas pelo usuário, e mostra o aviso na tela do IA Assist. A extensão não pede, não lê e não guarda a senha dos portais; quando a sessão expira, ela pede que o próprio usuário entre de novo. O recurso pode ser desligado no popup, em "Exportação automática".

Confirmação de chegada (a partir da versão 2.0.15): quando uma ordem de serviço do Aciona Fácil, da Tempo/Juvo ou da Mondial passa para "em execução" no IA Assist (técnico no local), a extensão confirma a chegada no portal da seguradora digitando o código que o próprio portal pede — os 4 últimos dígitos do telefone do cliente, lido na tela da ordem de serviço. Esse código é usado só dentro do portal, não é gravado nem enviado a outro lugar. Cada portal pode ser desligado no popup, em "Exportação automática".

Mensagens do WhatsApp Web

A partir da versão 2.0, a extensão também consegue montar uma ordem de serviço a partir de uma mensagem recebida no WhatsApp Web, quando a seguradora envia o acionamento por lá em vez de um portal.

Isso acontece somente por ação explícita do usuário: ele seleciona o texto da mensagem com o mouse e clica no ícone da extensão. Sem essa seleção e esse clique, a extensão não tem acesso nenhum à página do WhatsApp.

Dado Finalidade Armazenado?
Texto que o usuário selecionou na mensagem Extrair os campos da OS (protocolo, endereço, serviço, agendamento) Não
Nome da conversa aberta Lembrar qual corporativo e produto o usuário escolheu naquela conversa Sim — chrome.storage local, no computador do usuário

O conteúdo da mensagem não é transmitido nem gravado. A leitura do texto e a montagem da ordem de serviço acontecem inteiramente dentro do navegador do usuário. O que sai do computador são apenas os campos da OS já montados, para a mesma API do IA Assist usada pelos portais — exatamente como acontece com qualquer outra exportação.

A extensão não declara permissão de acesso ao domínio do WhatsApp. O acesso é concedido pelo próprio navegador, para aquela aba, no momento em que o usuário clica no ícone, e expira quando ele sai da aba.

A extensão não lê a lista de conversas, não lê outras conversas, não lê mensagens não lidas e não lê nada que o usuário não tenha selecionado. Também não envia mensagens pelo WhatsApp em nenhuma hipótese.

3Registro de erros para o suporte

A partir da versão 2.0.10, quando a extensão não consegue ler ou exportar uma ordem de serviço, ela envia um registro do erro ao suporte do IA Assist. Assim o problema é identificado e corrigido sem que o usuário precise enviar arquivos ou capturas de tela.

Dado enviado Finalidade
Tipo do erro e mensagem técnica Saber o que falhou (campo não lido, OS recusada etc.)
Versão da extensão, portal e número da OS Localizar o caso e a versão afetada
Nome da empresa no IA Assist Saber qual cliente foi afetado
Identificador aleatório da instalação Agrupar erros repetidos. Não identifica a pessoa.
Cópia do texto da tela onde o erro ocorreu, sem dados pessoais Reproduzir e corrigir a leitura do portal
Antes do envio, a extensão remove nome, telefone, CPF/CNPJ, e-mail, placa e chassi do segurado, tanto dos campos da ordem de serviço quanto do texto da tela. São mantidos o endereço do atendimento, o serviço e o modelo do veículo, que são os dados necessários para corrigir a leitura.

Os registros ficam armazenados no Supabase, em servidores localizados em São Paulo (Brasil). São acessados apenas pela equipe de suporte, não são compartilhados nem vendidos e são apagados automaticamente após 60 dias. O envio ocorre quando há um erro e, a partir da versão 2.0.15, também para registrar o resultado (sucesso ou erro) de cada confirmação de chegada automática, com o número da OS, o portal e a empresa — sem o telefone nem o código digitado. Fora disso, a extensão não envia nada durante o uso normal.

O usuário pode desligar este envio a qualquer momento no popup da extensão, em "Diagnóstico e suporte" → "Enviar erros automaticamente ao suporte".

4O que a extensão NÃO faz

  • Não rastreia histórico de navegação
  • Não monitora atividade do usuário (cliques, teclado, mouse)
  • Não acessa páginas fora dos portais de seguradora listados e do IA Assist (o WhatsApp Web só com a seleção e o clique do usuário)
  • Não pede, não lê e não guarda senhas dos portais das seguradoras
  • Não executa código carregado de servidores externos
  • Não usa eval() nem carrega scripts remotos
  • Não envia dados pessoais para servidores do desenvolvedor da extensão. Envia apenas registros de erro sem dados pessoais, que podem ser desligados (seção 3).
  • Não vende, compartilha nem transfere dados a terceiros
  • Não usa dados para publicidade, perfis ou scoring

5Armazenamento local

A extensão utiliza chrome.storage.sync exclusivamente para salvar:

  • A URL da API do IA Assist (inserida pelo usuário)
  • O token de autenticação da API (inserido pelo usuário)

Esses dados são armazenados de forma sincronizada com a conta Google do usuário pelo próprio mecanismo do Chrome. O usuário pode removê-los a qualquer momento desinstalando a extensão ou limpando os dados de extensões nas configurações do Chrome.

Nenhum dado pessoal de segurados é armazenado em nenhum momento.

6Segurança

  • Toda comunicação com a API ocorre exclusivamente via HTTPS
  • A extensão bloqueia ativamente envios para URLs sem HTTPS
  • O token de API é transmitido apenas no cabeçalho Authorization da requisição
  • Todo o código da extensão é compilado localmente (Vite) e incluído no pacote — nenhum código remoto é carregado

7Permissões utilizadas

Permissão Motivo

8Contato

Em caso de dúvidas sobre esta Política de Privacidade, entre em contato com o desenvolvedor responsável pela extensão através do painel da Chrome Web Store ou diretamente com o administrador do sistema IA Assist da sua organização.
